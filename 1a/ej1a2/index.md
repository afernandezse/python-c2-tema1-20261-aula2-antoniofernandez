# Documentación del proyecto

Este proyecto presenta la documentación y ofrece funciones Python para
consultar sus secciones principales.

La documentación incluye:

- Instrucciones para instalar y preparar el proyecto.
- Referencia de las funciones disponibles en la API.
- Información sobre el despliegue de la documentación.

Consulta las páginas de [Instalación](instalacion.md) y de
[Referencia de la API](api.md) para obtener más detalles.
